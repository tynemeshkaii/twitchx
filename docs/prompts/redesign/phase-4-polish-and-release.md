# Redesign phase 4: полировка и релиз

Ты — senior frontend-инженер и QA в репозитории TwitchX. Это последняя
фаза редизайна. Структура и компоненты готовы. Задача — довести детали
(движение, доступность, светлая тема, состояния), сверить всё с исходным
замыслом, подготовить чек-лист проверки на маке и обновить документацию так,
чтобы следующие изменения не откатили систему.

## Перед началом

1. Прочитай `CLAUDE.md` и `docs/prompts/redesign/README.md`.
2. Убедись, что фаза 3 смержена: настройки без глобальной Save, карточка без

3. `make check`, `css_ownership`, `make preview` — всё зелёное.
4. Сделай полный прогон `make preview` и просмотри **все** PNG. Составь для
   себя список расхождений с README (макет, принципы) — это вход для шага
   4.5.

## Шаги

### 4.1 Движение

- Токены в `tokens.css`: `--duration-fast 150ms`, `--duration-normal 200ms`,
  `--duration-slow 280ms`, `--ease-out cubic-bezier(0.2, 0, 0, 1)`. Удали
  `--ease-spring`, `--scale-press`, `--duration-instant` и их использования
  (ховер и нажатие без пружины; нажатие — `opacity .8` или `--pressed-bg`).
  Сведи `--duration-view`, `--view-enter-duration`, `--view-exit-duration` к
  двум (`--view-exit 160ms`, `--view-enter 240ms`).
- `view-transitions.js`: проверь, что переходы работают для новых вью и
  навигации сайдбара; правило CLAUDE.md «`opacity: 0` до смены `display`»
  соблюдено; переход не запускается при повторном клике на текущий пункт.
- Ступенчатое появление карточек (`.card-enter`, 13 правил `nth-child`):
  оставить только для первой загрузки, задержка 15 ms × индекс через
  `--i` (стиль `style.setProperty('--i', idx)`, не `style.display`), максимум
  8 шагов.
- Поповеры и меню: появление `opacity` + `translateY(4px)` → 0 за
  `--duration-fast`. Модалки — `scale(.98)` → 1.
- `prefers-reduced-motion` (`reset.css`): все новые анимации гаснут; проверь
  через `page.emulateMedia({ reducedMotion: 'reduce' })` в харнессе (добавь
  сценарий `grid-reduced`).

### 4.2 Высокий контраст и доступность

- `reset.css`, блок `@media (prefers-contrast: more)`: удали селекторы
  элементов, которых больше нет (`#player-bar`-контролы, `#search-input`,
  `#filter-input`, `#sort-select`, `.platform-tab`, `.browse-platform-tab`
  и т. д. — grep каждого), добавь новые: `.segmented`, поповер аккаунта,
  меню, оверлей плеера, `.card-thumb` фокус, строки сайдбара. Добавь
  сценарий харнесса с `forcedColors`/`prefers-contrast: more`
  (`page.emulateMedia({ contrast: 'more' })` поддерживается Playwright ≥1.47;
  если нет — пропусти и отметь в PR).
- Пройди Tab по всем экранам харнессом: напиши в `tools/ui_preview/` скрипт
  `focus-walk.js`, который на каждом сценарии жмёт Tab 40 раз и снимает
  скрины, где фокус невидим (элемент в фокусе без `outline` и без
  `box-shadow` в computed style). Исправь найденное.
- `tests/test_accessibility.py`: все icon-only кнопки с доступным именем,
  табы с `aria-selected` — проверь, что новые кнопки (чип аккаунта, «…»,
  меню качества, кнопка-поле поиска) покрыты; если тест их не видит, расширь
  его.
- VoiceOver-пункты — в чек-лист для мака (навигация сайдбара, поповер,
  палитра, оверлей плеера).

### 4.3 Палитра акцентов и светлая тема

- Свотчи акцента в `settings.js` и `ACCENT_PALETTE` в
  `tests/test_contrast.py` должны совпадать. Проверь каждый акцент на обеих
  темах в харнессе (сценарий `grid` с `localStorage` акцента — посмотри, как
  `settings.js` применяет `--accent-h/s/l`). Если какой-то акцент сливается с
  `--live` (красный) или `--warn-yellow` — замени его и обнови тест.
- Финальный проход по светлой теме по всем сценариям: превью и оверлеи
  видео тёмные в обеих темах, разделители различимы, глифы Kick читаются.

### 4.4 Состояния

Пройди по каждому компоненту и проверь в харнессе (добавь сценарии в
`shoot.js`, данные — в `mock.js`):

- загрузка: скелетон сетки (`hideSkeletonGrid`), Browse loading, VODs loading;
- ошибка: `onStatusUpdate({type:'error'})` (тост), плеер `#player-error`,
  Browse с `errors`;
- пусто: нет избранного, все офлайн («All quiet»), пустой Browse, канал не в
  эфире, пустой мультистрим;
- длинные данные: название стрима 140 символов, ник 25 символов, 50
  избранных, 1.2M зрителей — ничего не вылезает и не обрезается без
  ellipsis;
- stale-данные: плашка stale (`onStatusUpdate({stale:true})`).

### 4.5 Сверка с замыслом

Сравни итог с README редизайна по пунктам и исправь расхождения, не выходя
за объём уже сделанного:

- нет `backdrop-filter` вне парящих слоёв, нет свечения, градиентов на
  кнопках, анимации фона;
- один акцент; зелёный — только успех/подключено; live — только `--live`;
- одна функция — одно место (фильтр платформ, поиск, refresh, настройки,
  аккаунты);
- шкала текста 11/12/13/15/22/28, веса 400/500/600/700;
- главный экран совпадает со схемой из README.

Всё, что требует новой функциональности, — в «Замечено, не сделано».

### 4.7 Чек-лист для мака (в описание PR)

Сведи в одном месте всё, что нельзя проверить в Chromium:

- обе темы и Auto с переключением темы системы на лету;
- запуск без вспышки цвета;
- интегрированный titlebar (если флаг включён): светофор, перетаскивание,
  двойной клик;
- стрим 30+ минут: proactive reset и health-мониторы не ломают оверлей,
  fullscreen не выходит сам;
- fullscreen (контролы AVKit), PiP, мультистрим на 4 слота, звук скрытых
  слотов;
- замер GPU/CPU за минуту воспроизведения против замера до фазы 1;
- VoiceOver по пунктам из 4.2;
- окна 700×500, 960×640, во весь экран.
